# Masa Tenisi (oyun-masa-tenisi)

Masa Oyunları merkez uygulamasındaki masa tenisi oyunu. Parmağını sürükleyerek raketi yönetir, botlara karşı rallileri kazanırsın.

- 33 dil; kampanya, günlük, zen, sonsuz ve zamana karşı modları
- Seviyeler `studio_core` seviye planlayıcısıyla üretilir; aynı tohum aynı maçı verir
- Testler: `flutter test`

Kullanım: `import 'package:oyun_masa_tenisi/oyun_masa_tenisi.dart';` ve `masaTenisiConfig`.
